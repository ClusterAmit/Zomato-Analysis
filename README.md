# Restaurant Price Segmentation & Couple Spending Analysis

## Project Overview

This project focuses on analyzing **restaurant pricing and couple-oriented spending patterns** using a structured restaurant-level dataset. Since individual customer transactions are not available, the analysis uses **proxy pricing and engagement indicators** to infer spending behavior, affordability segments, and value-for-money insights. The output is designed for an **Excel-based analytical dashboard**.

---

## Dataset Description

The dataset contains restaurant attributes including location, cuisine, pricing, delivery options, ratings, and popularity indicators. Key fields used in the analysis include:

* Restaurant identity and geography (City, Locality, Coordinates)
* Pricing attributes (Average_Cost_for_two, Price_range, Price_in_USD_for_two)
* Engagement metrics (Votes, Rating)
* Service availability (Table Booking, Online Delivery)

---

## Price Segmentation Logic

The core metric used for price segmentation is **Average_Cost_for_two**, as it directly represents expected spending for a couple and is intuitive for business interpretation.

Restaurants are classified into the following segments:

* **Budget**: ≤ 500
* **Mid-Range**: 501 – 1200
* **Premium**: 1201 – 2500
* **Luxury**: > 2500

This segmentation enables clear comparison of affordability, demand, and customer perception across restaurant categories.

---

## Key Analytical Insights

The analysis highlights:

* Distribution of restaurants across price segments
* Average ratings and vote counts by price category
* Cuisine and city-level variations in couple spending
* Relationship between pricing and perceived value (ratings vs cost)

These insights help identify **value-for-money restaurants**, **premium dining preferences**, and **market positioning trends**.

## Dashboard Features (Excel)

The Excel dashboard includes:

* KPI cards for average cost, ratings, and restaurant counts
* Price segment-wise breakdowns
* Cuisine and city comparisons
* Interactive filters for location, cuisine, and price segment
